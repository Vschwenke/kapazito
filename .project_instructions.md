# Kapazito - Project Instructions

## Overview
Kapazito ("Dein Kapazitäts-Cockpit") is a SaaS BI platform for Professional Services companies. Rebranded from ServiceIQ (formerly PulseBI).

## Brand
- Name: Kapazito
- Tagline: "Kapazitäten klar im Blick"
- Logo: Activity icon (teal gradient), no text initials
- Colors: 
  - Primary: Teal (#1a9a8a / hsl 172 66% 40%)
  - Accent: Violet (#7c5cfc / hsl 262 60% 58%)
  - Charts: #1a9a8a (teal), #7c5cfc (violet), #f59e42 (amber), #e8577a (rose), #38bdf8 (sky), #34d399 (mint)
  - Success: #34d399, Warning: #f59e42, Danger: #e8577a
- Sidebar: slate-900 gradient, teal active states
- UI Style: Modern glass cards, gradient mesh backgrounds, rounded-2xl elements, shadow-sm borders

## Auth
- NextAuth v4, credentials provider
- Admin: admin@kapazito.de / Kapazito2026!
- Demo: demo@kapazito.de / Demo2026!
- All routes except /login protected via middleware

## Tech Stack
- Next.js 14, React 18, Tailwind CSS 3, Recharts, PostgreSQL + Prisma, NextAuth v4
- LLM API: gpt-4.1-mini via Abacus AI
- Named import: `import { prisma } from '@/lib/db'` (NOT default import)
- Color constants: `import { CHART_COLORS, CHART, STATUS_COLORS } from '@/lib/colors'`

## Modules (Complete)
1. **Executive Dashboard** (/dashboard) - KPIs, Gauges, Charts, Alerts, Cashflow, Aging
2. **Finanzen** (/finanzen/*) - Dashboard, Planung, Deckungsbeitrag (ECHTKOSTEN), Erträge, Betriebskosten
3. **HR & Team** (/hr/*) - Team-Übersicht, Mitarbeiter, Abwesenheiten
4. **Sales & CRM** (/sales/*) - Dashboard, Erträge, Projekt-Controlling
5. **Rechnungen** (/rechnungen/*) - Kundenübersicht, Details
6. **Stammdaten** (/stammdaten/*) - Kunden, Mitarbeiter, Projekte CRUD
7. **Zeiterfassung** (/zeiterfassung) - Wochenansicht, Stunden buchen
8. **Projekt-Controlling** (/projekte) - Budget vs. Verbrauch, Profitabilität
9. **Abwesenheiten** (/abwesenheiten) - Urlaub/Krank/Feiertag CRUD
10. **BWA-Import** (/import) - CSV-Import für Finanzdaten
11. **KI-Assistenten** (/agent) - 4 Agenten mit echten KPI-Daten
12. **System** (/base/*) - Datenübersicht, Konfiguration

## Design System
- Card radius: rounded-2xl
- Border: border-border/40, hover:border-border/60
- Shadows: shadow-sm default, hover:shadow-md
- Background: gradient-mesh (subtle radial gradients)
- Headers: backdrop-blur-xl, bg-background/70
- Gauge glow: filter drop-shadow with chart color
- KPI badges: colored bg for delta values
- Scrollbar: 5px thin, muted colors

## Database
- ~17 tables, comprehensive demo data (2024-2026)
- ~3,738 rows across all tables
- Shared dev/prod
- Key models: Customer, Employee, Project, TimeEntry, Invoice, FinancialAccount, PersonnelCost, etc.
