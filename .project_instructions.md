# INLOGY Reporting App

## Overview
Business Intelligence reporting system replicating 5 Power BI reports:
1. Finanzreport (BWA, Cashflow, P&L)
2. HR & Recruiting (utilization, turnover, salaries)
3. Sales & CRM (hourly rates, CRM pipeline)
4. Rechnungsstellung (invoicing, billing)
5. Base Report (data model overview)

## Design
- Dark sidebar navigation with INLOGY branding
- Professional BI dashboard aesthetic
- Color palette: Primary #1e40af (blue), Accent #0ea5e9, Success #10b981, Warning #f59e0b, Danger #ef4444
- Charts: Recharts with colors #60B5FF, #FF9149, #FF9898, #FF90BB, #80D8C3, #A19AD3
- KPI cards with delta indicators (green up, red down)
- Gauge visualizations for percentages

## Tech
- Next.js 14, React 18, Tailwind CSS 3
- PostgreSQL + Prisma ORM
- Recharts for data visualization
- Framer Motion for animations

## Data Model
Simplified from 31 Power BI tables to ~15 PostgreSQL tables covering:
- Customers, Employees, Projects
- Time entries, Absences, Holidays
- Financial accounts (BWA), Personnel costs
- Invoices, Financial planning
