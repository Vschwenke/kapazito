# PulseBI – Business Intelligence für IT-Dienstleister

## Overview
Eigenständige BI-Plattform (SaaS-Produkt) mit 5 Modulen + KI-Assistenten:
1. Finanzen (BWA, Cashflow, P&L, Deckungsbeitrag)
2. HR & Team (Auslastung, Fluktuation, Gehälter)
3. Sales & CRM (Stundensätze, Kundenanalyse)
4. Rechnungen (Billing, Stundenerfassung)
5. System (Datenübersicht, Konfiguration)
6. KI-Assistenten (Finanz-Analyst, HR-Berater, Sales-Stratege)

## Auth
- NextAuth.js v4 with credentials provider
- Login at /login, protected routes via middleware
- Admin user: admin@pulsebi.de / PulseBI2026!
- SessionProvider wraps entire app

## Design
- Dark sidebar navigation with PulseBI branding (PB logo)
- Professional BI dashboard aesthetic, no Power BI references
- Color palette: Primary #1e40af (blue), Accent #0ea5e9, Success #10b981, Warning #f59e0b, Danger #ef4444
- Charts: Recharts with colors #60B5FF, #FF9149, #FF9898, #FF90BB, #80D8C3, #A19AD3
- KPI cards with delta indicators (green up, red down)
- All data is fictional demo data (no real company names)

## Tech
- Next.js 14, React 18, Tailwind CSS 3
- PostgreSQL + Prisma ORM (User, ChatMessage models added)
- Recharts for data visualization
- LLM API (gpt-4.1-mini) for AI agents
- bcryptjs for password hashing

## Data Model
~17 PostgreSQL tables:
- User, ChatMessage (auth + AI)
- Customers, Employees, Projects
- Time entries, Absences, Holidays
- Financial accounts (BWA), Personnel costs
- Invoices, Financial planning

## Important
- NO Power BI, Clockodo, DATEV, Dataverse, SharePoint references anywhere
- All customer/employee names are fictional
- Data sources shown as: Zeiterfassung, Buchhaltung, Stammdaten, Projektverwaltung, Rechnungsmodul
