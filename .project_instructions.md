# ServiceIQ - Project Instructions

## Overview
ServiceIQ ("Intelligence Quotient für dein IT-Service-Business") is a SaaS BI platform for IT service companies. Rebranded from PulseBI.

## Brand
- Name: ServiceIQ
- Logo: SQ (blue square)
- Colors: Primary #1e40af, Charts: #60B5FF, #FF9149, #FF9898, #FF90BB, #80D8C3, #A19AD3
- Dark theme with slate-900 sidebar

## Auth
- NextAuth v4, credentials provider
- Admin: admin@serviceiq.de / ServiceIQ2026!
- All routes except /login protected via middleware

## Tech Stack
- Next.js 14, React 18, Tailwind CSS 3, Recharts, PostgreSQL + Prisma, NextAuth v4
- LLM API: gpt-4.1-mini via Abacus AI
- Named import: `import { prisma } from '@/lib/db'` (NOT default import)

## Modules (Sprint 1+2 - Completed)
1. **Executive Dashboard** (/dashboard) - KPIs, Gauges, Charts, Alerts, Cashflow, Aging
2. **Finanzen** (/finanzen/*) - Dashboard, Planung, Deckungsbeitrag (ECHTKOSTEN), Erträge, Betriebskosten (echte BWA-Kategorien)
3. **HR & Team** (/hr/*) - Team-Übersicht, Mitarbeiter, Abwesenheiten
4. **Sales & CRM** (/sales/*) - Dashboard, Erträge, Projekt-Controlling
5. **Rechnungen** (/rechnungen/*) - Kundenübersicht, Details
6. **Stammdaten** (/stammdaten/*) - Kunden, Mitarbeiter, Projekte CRUD
7. **Zeiterfassung** (/zeiterfassung) - Wochenansicht, Stunden buchen
8. **Projekt-Controlling** (/projekte) - Budget vs. Verbrauch, Profitabilität, Team, Forecast
9. **Abwesenheiten** (/abwesenheiten) - Urlaub/Krank/Feiertag CRUD, MA-Übersicht
10. **BWA-Import** (/import) - CSV-Import für Finanzdaten
11. **KI-Assistenten** (/agent) - 4 Agenten mit ECHTEN KPI-Daten als Kontext
12. **System** (/base/*) - Datenübersicht, Konfiguration

## Sprint 2 Changes
- Deckungsbeitrag: Uses real PersonnelCost × Allocation instead of 47% simulation
- Betriebskosten: Tries real BWA sub-categories before falling back to estimates
- KI-Agenten: All agents receive full business data (Finanzen, HR, Sales, Rechnungen)
- CSV Export: Available on Deckungsbeitrag, Betriebskosten, Projekt-Controlling, Abwesenheiten

## Key KPIs in Dashboard
Revenue/Employee, Personalkosten-Quote, DSO, Bench-Quote, Billable Ratio, Break-Even-Auslastung, HHI (Kundenkonzentration), Aging-Analyse, Echtkosten-Deckungsbeitrag
